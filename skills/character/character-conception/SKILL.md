# Character Conception

## Identity

**Purpose:** Generate a character concept — role, core contradiction, and a one-paragraph sketch — before full character construction begins. This is the idea-generation and filtering phase only. Operates in two modes depending on when in the project it is invoked.

---

## Core

Generate a character concept using one of four methods: role-first, archetype-subversion, historical inspiration, or "What If?". Identify the **core contradiction** — the internal tension that makes the character interesting and unpredictable rather than a function of their role. Output a concept document; do not build psychology, backstory, or plot placement.

---

## Invocation Modes

### Standard Mode

Invoked **after Worldbuilding has run** and Module 3.1 (Political/Power Map) is populated. The main agent provides a Module 3.1 excerpt as the primary world context. This is the default mode for all character conception work during and after the worldbuilding phase.

### Early Invocation Mode

Invoked **during the Defining Rough Endpoints two-pass process**, before Worldbuilding has run and before Module 3.1 exists. Used to conceive characters implied by draft milestones so that milestone logic can be grounded in character psychology rather than abstract story structure.

In early invocation mode, the main agent provides a **character slot sketch** (produced by Defining Rough Endpoints Pass 1) and a **world context sketch** derived from the endpoint compass and seed, in place of Module 3.1. These substitutes are thinner than a fully populated Module 3.1 — the world is not yet built — and the character concept produced may need to be revisited once Worldbuilding has run and the political map is populated.

> **Important:** A character concept produced in early invocation mode is a working document, not a final one. The main agent should flag it for review after Worldbuilding completes and re-invoke Character Conception (or Character Creation's revision process) if the world context materially changes the character's plausibility or role.

## Input

### Standard Mode

1. **World Bible excerpt — Module 3.1 (Political/Power Map):** Faction alignments, power structures, narrative gaps.
2. **Narrative role requirements (from main agent):** What story function this character must serve.
3. *(Optional)* **Research material** from Research Integration.
4. *(Optional)* **Thematic or tonal constraints.**

### Early Invocation Mode

1. **Character slot sketch** from Defining Rough Endpoints Pass 1, containing:
   - Narrative role in the milestone
   - Implied contradiction (hypothesis from Defining Rough Endpoints)
   - Stakes in the milestone
   - World context available from the endpoint compass and seed
   - Open questions about this character
2. **World context sketch** — a brief description of the political and social landscape implied by the endpoint compass and seed. Substitutes for Module 3.1. Will be thinner than a fully populated political map.
3. *(Optional)* **Thematic constraints** from the seed document (genre, themes, thematic interdependencies).

> In both modes, this skill receives context from the main agent. It does not access the World Bible directly.

---

## Output

A **character concept document** containing:

1. **Assigned narrative role** — what story function this character fills.
2. **Generation method used** — which of the four methods produced the concept, and brief reasoning.
3. **Core contradiction** — the single internal tension that makes the character interesting. Stated as a conflict between two drives, values, or identities. This is the seed of all future psychological development.
4. **One-paragraph sketch** — a compressed, vivid impression of who this character is: how they hold themselves in the world, what they want on the surface, what the core contradiction looks like from the outside. Prose only — no bullet points, no trait lists.
5. **Open questions** — 3–5 questions the concept raises that Character Creation will need to answer.
6. *(Early invocation mode only)* **Provisional flag** — a note stating that this concept was produced before Worldbuilding, identifying which elements are most likely to require revision once Module 3.1 is populated, and specifying what world-context information would most change the concept if it turned out differently than assumed.

The main agent does **not** update the World Bible from this output — no World Bible writes occur at this stage in either mode.

---

## Boundary

- **Does not** build psychological depth, core wound, fear/desire architecture, or arc type. That is Character Creation's domain.
- **Does not** place the character in the plot or assign them to specific events. That is Character Integration with Plot's domain.
- **Does not** write scenes or prose involving this character.
- **Does not** update the World Bible. Output is a concept document only.
- **Does not** define voice or narrative register. That is Character Voice Differentiation's domain.
- **Does not** generate multiple final candidates for the main agent to choose between — outputs one concept. If rejected, the main agent re-invokes the skill.
- **In early invocation mode, does not** attempt to fill in world detail that has not yet been established — works only from what the endpoint compass and seed actually provide, and flags assumptions explicitly in the provisional note.

---

## Invocation

**Standard mode:** After Worldbuilding has produced Module 3.1, whenever a new character is needed — new roles, new major figures, elevation of a minor character.

**Early invocation mode:** During the Defining Rough Endpoints two-pass process — specifically after Pass 1 has produced character slot sketches and before Pass 2 can be completed. The main agent invokes this skill once per slot sketch. The resulting concept documents are passed back to Defining Rough Endpoints for Pass 2, where milestones are refined using character logic.

In both modes, Character Conception is always invoked **before** Character Creation. It is never skipped to go directly to Character Creation.

## Instructions

### Step 1 — Identify the invocation mode

Determine which mode applies based on what the main agent has provided:
- If a Module 3.1 excerpt is present: **Standard mode**.
- If a character slot sketch and world context sketch are present (no Module 3.1): **Early invocation mode**.

In early invocation mode, read the slot sketch carefully. Note what the endpoint compass and seed have established about the world. Note what has *not* been established — these are the assumptions that will need to be flagged in the provisional note.

### Step 2 — Review the narrative requirement

Read the main agent's stated narrative role requirement and any thematic constraints. Identify what gap in the story's power map, faction structure, or POV landscape this character must fill. Do not invent a character who duplicates an existing character's function.

In early invocation mode, the "power map" is the world sketch from the compass and seed — thinner, but workable. Focus on the milestone's specific needs and the story's thematic logic rather than attempting to reconstruct a full political landscape that has not yet been built.

### Step 3 — Select a generation method

Choose the method most suited to the narrative requirement and existing cast:

- **Role-First:** Begin with the story function, then ask what kind of *person* — not archetype — would hold that role and have survived in it. Work inward from the role to the human.
- **Archetype-Subversion:** Identify the most expected version of this character. List expected attributes. Invert or complicate three of them in ways that are internally coherent — the result must feel earned, not contrarian.
- **Historical Inspiration:** Draw on a real historical figure (or, for speculative genres, a fictional precedent — see Research Integration) whose situation rhymes with the story's needs. Extract the structural pattern without copying biography. Synthesise with the world's specific context.
- **"What If?":** Pose a specific character question and follow the logic of who that person would have to be.

### Step 4 — Find the core contradiction

The core contradiction is not a quirk or a flaw. It is a genuine internal conflict between two things the character cannot reconcile. Test: *If this character is pushed to the limit, which side wins? And what does it cost them?* If that question cannot be answered, the contradiction is not yet real.

In early invocation mode, the slot sketch from Defining Rough Endpoints provides an *implied* contradiction — a hypothesis based on the milestone's needs. This may be confirmed, refined, or replaced. Do not treat it as locked; it is a starting hypothesis, and the generation methods may produce a more interesting or more coherent contradiction.

State the contradiction as: **[Drive or value A] / [Drive or value B]** — one line.

### Step 5 — Write the one-paragraph sketch

100–200 words. Convey this character's presence and the shape of their contradiction without explaining either directly. Use concrete detail, not abstraction. Prose only — no bullet points, no trait lists.

### Step 6 — Generate open questions

3–5 questions the concept raises that Character Creation must answer. Probe: the origin of the contradiction, what the character wants on the surface vs. what they actually need, where loyalty breaks or self-deception is most dangerous, how the contradiction might evolve across a long arc.

### Step 7 — Write the provisional flag (early invocation mode only)

Identify:
- Which elements of the concept rest on world-context assumptions that have not yet been established by Worldbuilding.
- Which assumptions are most likely to change once Module 3.1 is populated.
- What specific world-context information (e.g. the nature of a specific faction, the mechanics of a specific power structure) would most change the concept if it turned out differently than assumed.

This flag allows the main agent to know exactly what to re-examine after Worldbuilding runs.

### Step 8 — Assemble and return the concept document

Return the complete concept document to the main agent. In early invocation mode, the main agent routes it to Defining Rough Endpoints for Pass 2 milestone refinement before passing it onward to Character Creation.

## Quality Checks

Before returning output, verify:

- [ ] Invocation mode was correctly identified from the input.
- [ ] Core contradiction is a genuine internal conflict, not a quirk or tragic flaw label.
- [ ] Sketch is prose — no bullet points, no trait lists.
- [ ] Character does not duplicate an existing character's narrative function.
- [ ] No psychological depth, backstory, or arc specification added (that is Character Creation's job).
- [ ] No World Bible writes specified.
- [ ] Open questions are genuinely open — they probe, they do not answer.
- [ ] In early invocation mode: provisional flag is present, specific, and actionable.
- [ ] In early invocation mode: no world-context details were invented beyond what the compass and seed actually establish; all assumptions are flagged.
